# Sync Room Game 🎮

A real-time multiplayer browser game where friends, family, or classmates can join and play together from their own devices using a shared room code—no login or installation required.

## ✨ Features
- **Instant Room Codes:** Create a game room and share a simple code for others to join immediately.
- **Real-Time State Synchronization:** Every player's screen stays in sync across phones, tablets, and laptops.
- **Zero Friction:** Play directly in the browser without creating accounts or installing apps.
- **Self-Explanatory Rules:** Built-in onboarding so new players can jump straight into the action.
